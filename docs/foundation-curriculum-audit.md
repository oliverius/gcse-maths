# Foundation curriculum audit

References updated 19 October 2026. Baseline: **32 working lessons**; after this batch: **44 working lessons**, six subject JSON files, no interactive placeholders. This audit uses **England GCSE Mathematics, Pearson Edexcel 1MA1 Foundation**. Use the specification?s dedicated Foundation section (printed pages 5?11), including standard and underlined content.

Sources: [DfE publication][DfE], [DfE subject-content PDF][PDF], and the Pearson Edexcel specification subject sections linked below. DfE supplies the national framework; Pearson?s dedicated Foundation section resolves eligibility. Links use PDF page numbers including the cover pages.

**Status:** covered = a complete, bounded worked concept; partial = some examples exist but breadth or prerequisites remain; missing = no lesson; not Foundation = the indicated extension is outside Edexcel Foundation. Covered does **not** mean full exam mastery. Priority P1 = prerequisite/high value, P2 = next batch, P3 = later extension, — = retain/exclude. Dependencies refer to concepts or lesson IDs.

## Implementation batch and acceptance

Implemented batch: five Number powers/roots lessons; three Geometry Pythagoras lessons; prime decomposition, place value ×10, substitution, and a coin/spinner sample space. **44** lessons are available. No claim of completing the whole Foundation specification; remaining P1/P2 rows stay on the roadmap.

Sequence: `square-three` → `cube-two` / `square-root-25` → `zero-power` / `multiply-powers`; squares and roots → `pythagoras-areas` → both Pythagoras calculations. Prime decomposition and place-value work can be taught before standard form/HCF; substitution precedes graphs. Each new lesson includes a tutor explanation question, no typing or marking.

Pythagoras examples use exact geometry and integer answers. The 3–4–5 area lesson illustrates the relationship with unit squares; it does not claim that checking one triangle proves the general theorem. The worked unknowns remain unlabelled until calculated, even though the drawing is to scale. Roots are principal nonnegative roots; solving a squared equation for unrestricted real numbers is a different lesson. Exponent zero uses a nonzero base and does not teach `0^0`.
